================================================================================
QUICK START GUIDE
================================================================================

1. INITIALIZE REPOSITORY:
   python facefusion_repo_cli.py init

2. ADD A PERSON:
   python facefusion_repo_cli.py add-person --person marc --display-name "Marc"

3. ADD FACES:
   python facefusion_repo_cli.py add --source face.jpg --person marc

4. CREATE SETTINGS:
   python facefusion_repo_cli.py repo-settings-create --name hq --template high_quality

5. CREATE PRESET:
   python facefusion_repo_cli.py repo-presets-create --name marc_hq --person marc --settings hq

6. VIEW STATISTICS:
   python facefusion_repo_cli.py stats

7. LAUNCH GUI:
   python facefusion_repo_gui.py
   # Access at http://127.0.0.1:7861
