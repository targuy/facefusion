   - Warnings: ⚠️ (si overlap/low quality)
3. Sauvegarder thumbnails annotés dans cache temporaire
4. Passer chemins annotés à `REPOSITORY_FACE_GALLERY`

**Code exemple**:
```python
from PIL import Image, ImageDraw, ImageFont

def annotate_thumbnail(face_path: str, metadata: dict) -> str:
    img = Image.open(face_path)
    draw = ImageDraw.Draw(img)
    
    # Quality stars
    quality = metadata.get('quality', {}).get('overall', 0)
    stars = '⭐' * int(quality * 5)
    draw.text((10, 10), stars, fill='yellow')
    
    # Orientation arrow
    yaw = metadata.get('pose', {}).get('yaw', 0)
    if -30 < yaw < 30:
        arrow = '→'
    elif yaw >= 30:
        arrow = '↗'
    else:
        arrow = '↖'
    draw.text((10, 40), arrow, fill='blue')
    
    # Save to temp
    temp_path = f'/tmp/annotated_{os.path.basename(face_path)}'
    img.save(temp_path)
    return temp_path
```

**Algorithme de conversion**:
```python
def orientation_to_xyz(pitch: float, yaw: float) -> Tuple[float, float, float]:
    pitch_rad = np.radians(pitch)
    yaw_rad = np.radians(yaw)
    x = np.cos(pitch_rad) * np.sin(yaw_rad)
    y = np.cos(pitch_rad) * np.cos(yaw_rad)
    z = np.sin(pitch_rad)
    return x, y, z
```
